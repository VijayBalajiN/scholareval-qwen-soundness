## Strengths 
The strongest support is for an IOL-derived, language-agnostic benchmark with self-contained puzzles, exact-match primary scoring, chrF secondary scoring, 0-5 in-context examples, and open-versus-proprietary model comparison. [(Sánchez et al., 2024-09)](https://www.semanticscholar.org/paper/9b6c35db256e38496ad81c189783529ab4209960) directly evaluates Linguini-style IOL puzzles with exact match, chrF, 0-5 examples, and an open-proprietary gap. [(Bean et al., 2024-06)](https://www.semanticscholar.org/paper/299cbb7e4c7e676e81d87d28efb8701df8892ec4) supports Olympiad-style JSONL construction, exhaustive acceptable answers, exact match, and contamination-aware scoring. [(Şahin et al., 2020-04)](https://www.semanticscholar.org/paper/2e0fab543b49b315d29b0d81e8f958707456f69e) validates IOL/NACLO extraction into machine-readable parallel instances and exact match for short unambiguous items. [(Chi et al., 2024-06)](https://www.semanticscholar.org/paper/e35c5f517e547bde2ae4d77a535d3e5584805f02) supports extremely low-resource Rosetta Stone puzzles, exact match, difficulty ratings, and model-tier analysis. The 0-5 sweep is also supported by [(Gao et al., 2023-08)](https://www.semanticscholar.org/paper/894ed1aba8e42a4ec27ba53ecde383b14c5128ca), which shows shot effects are non-monotonic, and the script transliteration ablation is supported by controlled writing-system manipulation in [(Jung et al., 2024-02)](https://www.semanticscholar.org/paper/bc125af6e7071aae2ed2b46f1d45ea9adc42d916) and [(Muller et al., 2020-10)](https://www.semanticscholar.org/paper/29599829d26b4acaaf0ad88698ed4362d33b2ae7).

## Weaknesses 
The strongest contradictions target the assumption that context alone isolates reasoning and that simple exact-match/few-shot protocols are stable. [(Bean et al., 2024-06)](https://www.semanticscholar.org/paper/299cbb7e4c7e676e81d87d28efb8701df8892ec4) shows exact match can be inflated by memorization and resource familiarity, motivating a resourcing-adjusted score. [(Sánchez et al., 2024-09)](https://www.semanticscholar.org/paper/9b6c35db256e38496ad81c189783529ab4209960) shows in-context examples can help some models but hurt others, so 0-5 leave-one-out prompting must be a controlled ablation. [(Şahin et al., 2020-04)](https://www.semanticscholar.org/paper/2e0fab543b49b315d29b0d81e8f958707456f69e) shows IOL sequence transduction can be extremely hard under exact match, with maximum exact match only 3.4 percent, so normalization and metric brittleness matter. [(Bapna et al., 2022-05)](https://www.semanticscholar.org/paper/66de7ac94dd13ec041659b06041c6ff27b1e55f2) and [(Singh et al., 2024-06)](https://www.semanticscholar.org/paper/eed4140dfa751319c2952acf46a64ad79df545e2) warn that chrF can overestimate low-resource quality. [(Jung et al., 2024-02)](https://www.semanticscholar.org/paper/bc125af6e7071aae2ed2b46f1d45ea9adc42d916) and [(Gorman et al., 2020-07)](https://www.semanticscholar.org/paper/278f4f68309fc4ffb83bfc4ba86a0ea005106682) show script and transliteration changes can introduce representation and conversion confounds. [(Chang et al., 2024-08)](https://www.semanticscholar.org/paper/d23b8bce8d8abeab50fce08b6b7628ebb7de4d08) and [(Hasan et al., 2024-08)](https://www.semanticscholar.org/paper/8fcf5e276368c17d74e55d626a5ce5841bf64cdc) show resourcefulness is not a uniform predictor of performance. No-context prompting is also not a standalone contamination detector, as shown by [(Ziegler et al., 2024-09)](https://www.semanticscholar.org/paper/5616be414472881c170abca7ac2472378c63fc74) and [(Ubani et al., 2023-04)](https://www.semanticscholar.org/paper/ee1fdc0e4391f2ef7d3222d47d8677c574fcd95c).

## Top 3 Suggestions 
Add a self-containedness and contamination audit: require expert annotation that each item is solvable only from the provided context, record speaker count and online presence, use exhaustive acceptable answers and strict normalization, report exact match plus a resource-adjusted score analogous to ΔNC, and add n-gram or embedding overlap checks plus held-out or newly authored items; treat no-context prompting as a behavioral proxy rather than proof, following [(Bean et al., 2024-06)](https://www.semanticscholar.org/paper/299cbb7e4c7e676e81d87d28efb8701df8892ec4), [(Ziegler et al., 2024-09)](https://www.semanticscholar.org/paper/5616be414472881c170abca7ac2472378c63fc74), [(Ubani et al., 2023-04)](https://www.semanticscholar.org/paper/ee1fdc0e4391f2ef7d3222d47d8677c574fcd95c), and [(Sánchez et al., 2024-09)](https://www.semanticscholar.org/paper/9b6c35db256e38496ad81c189783529ab4209960).

Make the 0-5 leave-one-out few-shot protocol a controlled ablation: select same-format examples from different languages, exclude same script, lexical, and morphological overlap, add no-context, format-only, random-example, and prompt-position controls, run full 0-5 curves with multiple seeds, and report per-model and per-task curves with confidence intervals or paired bootstrap tests, because [(Gao et al., 2023-08)](https://www.semanticscholar.org/paper/894ed1aba8e42a4ec27ba53ecde383b14c5128ca), [(Sinha et al., 2022-10)](https://www.semanticscholar.org/paper/97833e2aa0da5240e62436373b58af988a4ab6ab), and [(Sánchez et al., 2024-09)](https://www.semanticscholar.org/paper/9b6c35db256e38496ad81c189783529ab4209960) show non-monotonic and model-dependent effects.

Validate the taxonomy, categories, and scoring before model evaluation: define operational criteria for morphosyntactic segmentation, morphosemantic alignment, derivation, morphophonological segmentation, and graphophonemic transcription; report item counts, inter-annotator agreement, IOL-medalist difficulty ratings, and per-category coverage; use exact match as primary with chrF or chrF++ and character error rate as secondary diagnostics, plus human spot-checks for ambiguous fill-in-blanks and transliteration, following [(Chen, and Gao, 2022-04)](https://www.semanticscholar.org/paper/32c6607346e0bbe21844275f55fb368bbffd4699), [(Pinter et al., 2020-09)](https://www.semanticscholar.org/paper/03826718c8c47d8f1f25e437fd6ff15165162e8c), [(Laverghetta et al., 2021-06)](https://www.semanticscholar.org/paper/3177b63f5d6ce3aa2e172eb5c94412fdaf3be5fd), [(Chi et al., 2024-06)](https://www.semanticscholar.org/paper/e35c5f517e547bde2ae4d77a535d3e5584805f02), and [(Puduppully et al., 2023-05)](https://www.semanticscholar.org/paper/b6e5855b6a4e425ba251a93516f2bccffe5ba403).
