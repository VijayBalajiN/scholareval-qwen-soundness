## Strengths 
The proposal is strongest where it uses executable code as an automatic semantic-diversity signal. Competitive-programming-derived tasks can be made execution-validated with enough tests [(Shypula et al., 2023-02)](https://www.semanticscholar.org/paper/1786a2f9140ed7211b21302977de64e948b92308), and CodeNet-derived Python tasks can be run safely in Docker/Judge0 while comparing base and instruction-tuned models [(Waghjale et al., 2024-07)](https://www.semanticscholar.org/paper/eb0db181546bd8493246d8f767b63d57ca4e686f). K=100 sampled programs per problem is feasible for execution labeling [(Inala et al., 2022-06)](https://www.semanticscholar.org/paper/075b6fb7d3787953164eecc1bd2e13f97c9f3c44), and behavior clustering over generated programs supports using execution outputs to separate semantic modes [(Li et al., 2022-02)](https://www.semanticscholar.org/paper/5cbe278b65a81602a864184bbca37de91448a5f5). The pairwise average distinctness design is aligned with Sim@K-style code diversity metrics [(Chon et al., 2024-08)](https://www.semanticscholar.org/paper/5db9709ceb0a81b7dfc741e9fe309f32a53d6d8c), and prompt-template control is justified because zero-shot, few-shot, and chain-of-thought prompts can materially change model behavior [(Kojima et al., 2022-05)](https://www.semanticscholar.org/paper/e7ad08848d5d7c5c47673ffe0da00af443643bda) [(Wei et al., 2022-01)](https://www.semanticscholar.org/paper/1b6e810ce0afd0dd093f789d2b2742d047e316d5). Neural metrics are plausible secondary instruments: CodeBERTScore has been evaluated for code similarity [(Zhou et al., 2023-02)](https://www.semanticscholar.org/paper/31366ff634fc905affd78dbd8ddc9a872c006a87), and ICE-Score is a validated LLM-based code evaluation signal [(Zhuo, 2023-04)](https://www.semanticscholar.org/paper/fbe90d2864ffdbefd1fc0a7c6f65ac10452052f2).

## Weaknesses 
The strongest contradictions concern validation and confounding. The 21-task open-ended abstraction of CodeNet is not directly supported; abstracting competitive tasks may change semantics or overconstrain solutions, and 21 tasks is smaller than comparable executable benchmarks [(Li et al., 2022-02)](https://www.semanticscholar.org/paper/5cbe278b65a81602a864184bbca37de91448a5f5) [(Waghjale et al., 2024-07)](https://www.semanticscholar.org/paper/eb0db181546bd8493246d8f767b63d57ca4e686f). K=100 and temperature=1.0 without nucleus sampling are not guaranteed to capture stable semantic diversity or maintain executable quality; related work uses larger sample budgets, lower temperatures, nucleus sampling, or duplicate control [(Li et al., 2022-02)](https://www.semanticscholar.org/paper/5cbe278b65a81602a864184bbca37de91448a5f5) [(Holtzman et al., 2019-04)](https://www.semanticscholar.org/paper/cf4aa38ae31b43fd07abe13b4ffdb265babb7be1) [(Shi et al., 2020-02)](https://www.semanticscholar.org/paper/c860d1560cf495895f931e09ffd698f77ede5b99). Pairwise averaging is not proven sample-size invariant, because the closest Sim@K work only tested K=10 and found correctness filtering changes diversity [(Chon et al., 2024-08)](https://www.semanticscholar.org/paper/5db9709ceb0a81b7dfc741e9fe309f32a53d6d8c). Neural diversity metrics are under-validated: CodeBERTScore can be weak or domain-sensitive [(Zhan et al., 2024-07)](https://www.semanticscholar.org/paper/2481f5378159eb053583b261b2515d85006f4515) [(Zhou et al., 2023-02)](https://www.semanticscholar.org/paper/31366ff634fc905affd78dbd8ddc9a872c006a87), and ICE-Score was designed for quality/correctness rather than diversity [(Zhuo, 2023-04)](https://www.semanticscholar.org/paper/fbe90d2864ffdbefd1fc0a7c6f65ac10452052f2). Finally, instruction tuning does not uniformly reduce diversity or quality, so the mode-collapse hypothesis must be tested rather than assumed [(Zeng et al., 2024-03)](https://www.semanticscholar.org/paper/d503e569c94a4d689a576bb994744adc49aef505) [(Ivison et al., 2023-11)](https://www.semanticscholar.org/paper/37680e5cb6030e01f1a44a5abe2257972196ae26) [(Xu et al., 2024-06)](https://www.semanticscholar.org/paper/cab3d65b3f4d0a4169d0fdaaed15af6be1d6bb84).

## Top 3 Suggestions 
Validate the execution-based semantic-diversity harness before main comparisons: for each CodeNet-derived task, collect accepted submissions, cluster execution behavior, require multiple valid algorithmic modes, add hidden/generated/property-based tests, Docker resource limits, timeout handling, and false-positive/coverage reports; then run saturation curves at K=10, 50, 100, and if feasible 500, with deduplication and separate all-program versus correct-program diversity [(Li et al., 2022-02)](https://www.semanticscholar.org/paper/5cbe278b65a81602a864184bbca37de91448a5f5) [(Shypula et al., 2023-02)](https://www.semanticscholar.org/paper/1786a2f9140ed7211b21302977de64e948b92308) [(Waghjale et al., 2024-07)](https://www.semanticscholar.org/paper/eb0db181546bd8493246d8f767b63d57ca4e686f) [(Inala et al., 2022-06)](https://www.semanticscholar.org/paper/075b6fb7d3787953164eecc1bd2e13f97c9f3c44) [(Chon et al., 2024-08)](https://www.semanticscholar.org/paper/5db9709ceb0a81b7dfc741e9fe309f32a53d6d8c).

Make the metric suite and statistical protocol explicit and validated: define bounded pairwise semantic, lexical, syntactic, and neural distinctness scores; treat execution-output distinctness as primary and EAD, AST Distinct-N, CodeBERTScore, and ICE-Score as secondary; validate neural scores against execution labels and a small human subset; report length, AST size, syntax-error, pass@k, and duplicate controls; test sample-size invariance by subsampling; and use problem-level Wilcoxon tests with exact p-values, confidence intervals, multiple-comparison correction, and mixed-effects or random-effects models for problem, model, prompt, and seed [(Chon et al., 2024-08)](https://www.semanticscholar.org/paper/5db9709ceb0a81b7dfc741e9fe309f32a53d6d8c) [(Zhou et al., 2023-02)](https://www.semanticscholar.org/paper/31366ff634fc905affd78dbd8ddc9a872c006a87) [(Zhuo, 2023-04)](https://www.semanticscholar.org/paper/fbe90d2864ffdbefd1fc0a7c6f65ac10452052f2) [(Ma et al., 2023-05)](https://www.semanticscholar.org/paper/2c933b2a293a1cceb69236d89db06addf5cc7c74) [(Li et al., 2015-10)](https://www.semanticscholar.org/paper/651e5bcc14f14605a879303e97572a27ea8c7956) [(Su et al., 2021-09)](https://www.semanticscholar.org/paper/841ca3d87a422451596b8a4b8350e92106971791).

Expand prompt and sampling controls to separate instruction tuning from decoding and prompt effects: use a factorial prompt design including zero-shot, zero-shot chain-of-thought, two-shot, and three-shot random/retrieved/task-matched demonstrations; separate chain-of-thought text from final code; report instruction-following validity; ablate temperature 0.4, 0.8, and 1.0 with and without nucleus p=0.95 plus a greedy correctness control; and compare base versus instruction-tuned checkpoints only within the same family and size, with matched SFT checkpoints and reported checkpoint, data, and API details [(Kojima et al., 2022-05)](https://www.semanticscholar.org/paper/e7ad08848d5d7c5c47673ffe0da00af443643bda) [(Wei et al., 2022-01)](https://www.semanticscholar.org/paper/1b6e810ce0afd0dd093f789d2b2742d047e316d5) [(Guo et al., 2024-02)](https://www.semanticscholar.org/paper/46a294a1ddc43517a9ad11d05da7af1e93e91a39) [(Holtzman et al., 2019-04)](https://www.semanticscholar.org/paper/cf4aa38ae31b43fd07abe13b4ffdb265babb7be1) [(Shi et al., 2020-02)](https://www.semanticscholar.org/paper/c860d1560cf495895f931e09ffd698f77ede5b99) [(Xu et al., 2024-06)](https://www.semanticscholar.org/paper/cab3d65b3f4d0a4169d0fdaaed15af6be1d6bb84) [(Zeng et al., 2024-03)](https://www.semanticscholar.org/paper/d503e569c94a4d689a576bb994744adc49aef505).
